## Zombie Mod Infection Remake

**Current Version:** 1.0  
**Author:** ProgramViewer  
**Licence:** GPL-3.0

---

## Description

**Zombie Mod Infection Remake** is a complete reimagining of the classic zombie infection mod for Counter-Strike 1.6, rooted in the original gameplay that became popular years ago. This project brings the traditional humans vs zombies experience into the modern era, adding new personal touches and refinements while keeping the essence that made the original mod so engaging. Built entirely from the ground up, it offers fresh ideas and improved mechanics, all under an open‑source license.
